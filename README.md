# CSS 能量工坊

一个不用图片、不用任何外部框架的纯前端放置类小游戏。
所有图标由 CSS 绘制，音效由本地音频文件播放，数据保存在浏览器本地，
排行榜通过 Supabase 提供云端支持。

> 打开 index.html 就能玩。

------------------------------------------------------------------
项目简介
------------------------------------------------------------------

CSS 能量工坊 是一个练习性质的纯前端项目。

所有视觉元素（图标、动画、装饰）全部由 CSS 绘制，
所有逻辑由原生 JavaScript 实现，
存档保存在 localStorage（加密），
排行榜通过 Supabase 提供云端支持。

| 项目       | 说明                                            |
|------------|-------------------------------------------------|
| 类型       | 点击放置 / 挂机升级 / 轻金融模拟                |
| 运行方式   | 纯前端多页面，直接打开 index.html               |
| 数据存储   | localStorage（加密） + Supabase 云端排行榜      |
| 外部依赖   | 无（Supabase 为可选，不配置也能玩）             |
| 兼容性     | 现代浏览器（Chrome / Edge / Safari / Firefox）  |

------------------------------------------------------------------
核心玩法
------------------------------------------------------------------

1. 点击能量核心获得能量
2. 用能量购买升级，提高点击收益和自动收益
3. 解锁成就，获得荣誉与影响力
4. 银行存钱吃利息，贷款玩杠杆
5. 投资理财，稳健或激进，承担风险博收益
6. 冲击排行榜，争夺资本排名

功能列表
------------------------------------------------------------------

【能量系统】
- 点击核心获得能量（支持暴击、连击、回响等特效）
- 自动收益：每秒自动增加能量
- 离线收益：关闭页面后按自动收益累计，默认最多 8 小时

【商店（12 个分区，20 个升级项）】
- 点击强化：提升点击收益
- 自动生产：提升自动收益
- 倍率强化：乘法叠加的倍率升级
- 暴击系统：暴击率 + 暴击倍率
- 自动点击：自动模拟点击
- 离线强化：提升离线上限与效率
- 里程碑：一次性购买的质变升级
- 点击特效：双倍点击、连锁点击
- 被动加成：全局被动增益
- 时间类：结算频率与投资周期
- 幸运类：投资成功率、暴击率加成
- 转化类：点击收益转入存款、存款利率强化

【成就树】
- 20 个成就，树形结构
- 有前置依赖：必须先解锁父节点
- 三种状态：已解锁 / 可解锁 / 锁定
- 带 CSS 连线的树状布局

【金融系统】
- 银行：存款吃利息、贷款（动态利率）、自动还贷
- 投资：4 档投资（稳健理财 / 平衡基金 / 激进股票 / 大额投资）
- 资本：综合存款、能量、购买力、影响力、欠款计算的综合数值

【排行榜】
- 基于 Supabase 的云端排行榜
- 支持本地回退（无网络时显示本地数据）
- 手动刷新
- 显示排名 / 玩家 ID / 资本 / 称号

【其他】
- 深色 / 浅色主题切换
- 数字缩写（1.5K）/ 完整（1,500）切换
- 存档加密（XOR + 十六进制）
- 存档导出 / 导入（支持文件选择与文本粘贴）
- 点击音效（本地音频文件）
- 游客状态拦截（未注册不能进其他页面）

本地运行
------------------------------------------------------------------

【方式一：直接打开】
双击 index.html，浏览器打开即可。

注意：file:// 协议下部分浏览器会限制文件选择器。
如果导入存档时选文件无反应，改用"粘贴文本"方式，或用方式二。

【方式二：本地服务器（推荐）】
在项目目录下运行任意静态服务器：

  # Python 3
  python -m http.server 8000

  # Node.js
  npx serve

  # PHP
  php -S localhost:8000

然后访问 http://localhost:8000

云端排行榜配置
------------------------------------------------------------------

排行榜依赖 Supabase 提供云端存储。
不配置也能玩，但排行榜只显示本地数据。

【1. 创建 Supabase 项目】
- 访问 supabase.com 注册账号
- 新建项目，记下 Project URL 和 anon public key

【2. 创建数据表】
在 Supabase 控制台的 SQL Editor 中执行：

  -- 创建排行榜表
  CREATE TABLE leaderboard (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    player_name TEXT NOT NULL UNIQUE,
    capital NUMERIC NOT NULL DEFAULT 0,
    title TEXT,
    click_count BIGINT DEFAULT 0,
    total_energy NUMERIC DEFAULT 0,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
  );

  CREATE INDEX idx_leaderboard_capital ON leaderboard (capital DESC);

  -- 开启行级安全
  ALTER TABLE leaderboard ENABLE ROW LEVEL SECURITY;

  -- 策略：所有人可读、可插入、可更新
  CREATE POLICY "public_read" ON leaderboard FOR SELECT USING (true);
  CREATE POLICY "public_insert" ON leaderboard FOR INSERT WITH CHECK (true);
  CREATE POLICY "public_update" ON leaderboard FOR UPDATE USING (true) WITH CHECK (true);

  -- 授权
  GRANT SELECT, INSERT, UPDATE ON leaderboard TO anon;
  GRANT SELECT, INSERT, UPDATE ON leaderboard TO authenticated;
  GRANT USAGE, SELECT ON ALL SEQUENCES IN SCHEMA public TO anon;
  GRANT USAGE, SELECT ON ALL SEQUENCES IN SCHEMA public TO authenticated;

【3. 填写配置】
打开 js/supabase-config.js，修改前两行：

  const SUPABASE_URL = 'https://你的项目ID.supabase.co';
  const SUPABASE_ANON_KEY = '你的 anon public key';

重要：使用 anon public key，不要用 service_role key。
      也不要放后端密钥到前端。

【4. 测试】
打开排行榜页，点击"测试云端"按钮，会显示 5 步诊断：

  步骤1：SDK 已加载
  步骤2：配置已加载
  步骤3：玩家 ID = xxx
  步骤4：上传成功
  步骤5：拉取成功，云端有 N 位玩家

全部通过即表示云端正常。

存档系统
------------------------------------------------------------------

【存储位置】
- 主存档：localStorage 键 css_energy_workshop_save_v2
- 备份存档：localStorage 键 css_energy_workshop_save_v2_backup

【加密方式】
1. 存档对象 → JSON 字符串
2. UTF-8 编码 → 字节数组
3. 与固定密钥进行 XOR 异或
4. 转成十六进制字符串
5. 加前缀 CEW2: 存储

注意：这是混淆级加密，用于避免存档被一眼读懂，
      并非真正的安全加密（密钥在前端代码中可见）。

【保存时机】
- 每次点击核心
- 每次购买升级
- 每次成就解锁
- 每 5 秒定时保存
- 页面关闭前保存
- 切回前台时保存

【导出 / 导入】
- 导出：设置页可导出加密字符串，或下载 .json 文件
- 导入：设置页或首页"导入外部存档"按钮，
        支持选文件或粘贴文本

【兼容性】
normalizeSave 函数会为缺失字段填入默认值，
因此旧版本存档也能正常读取。

开发笔记
------------------------------------------------------------------

【资本公式】
资本 = 存款
     + 投资中的本金
     + 当前能量 × 0.1
     + 总升级等级 × 50 × 0.3
     + 已解锁成就数 × 20
     - 欠款 × 3

【收益公式】
点击收益 = (1 + 点击核心加成) × (1.08 ^ 指尖共鸣) × (1.05 ^ 全局增幅)

自动收益 = 自动核心加成
         × (1.08 ^ 能量回路)
         × (1.05 ^ 全局增幅)
         × (1 + 0.02 × 能量护盾)
         × (1 + 共鸣加成)

【价格公式】
价格 = 基础价格 × 增长率 ^ 当前等级（向下取整）

【暴击公式】
暴击率 = min(5% + 1.5% × 暴击训练，75%) × (1 + 1% × 命运骰子)
暴击倍率 = 5x + 0.5x × 暴击强化

【离线收益】
离线收益 = min(离线秒数, 离线上限 × 3600) × 自动收益 × 离线效率

【已知限制】
- 存档加密为混淆级，不能防止有心人破解
- 排行榜依赖 Supabase，国内网络可能不稳定，
  建议使用 Cloudflare Workers 反代
- 手机浏览器对文件选择器支持不一，
  如遇问题用"粘贴文本"方式导入
